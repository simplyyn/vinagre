O Problema

Classificar trechos de notícia sem ver o texto completo

O produto final recebe até 50 palavras de uma notícia (início da matéria ou boato citado) e deve responder: TRUE ou FAKE.

Entrada

Trecho de 30–50 palavras: início da matéria (true) ou boato citado entre aspas (fake).

Saída

Classe (TRUE ou FAKE) + confiança = distância da fronteira de decisão do SVM.

Desafio

Texto incompleto, sem contexto externo, múltiplas fontes e estilos de redação muito diferentes.

Dados

Três corpora, um formato só

O modelo final usa FakeRecogna 2020–21 + corpus externo coletado no formato do produto.

FakeRecogna 2.0 — 2020–21 (treino)

  • 4.660 itens: 2.330 fake × 2.330 true
  • Fake: Boatos.org, E-farsas, Aos Fatos, Lupa…
  • True: resumos automáticos de notícias reais
  • Apenas anos 2020–2021 (onde as duas classes existem)
  • Tipo fake: boato citado e outros (sem textos de checagem)

Corpus Externo 2022–2026 (treino + validação)

  • 2.849 itens coletados via RSS no formato do produto
  • Fake: Boatos.org 810, E-farsas 112
  • True: G1 1.824, Agência Brasil 103
  • Split temporal: treino até ago/2026, validação ago–set/2026
  • Validação: 855 itens — toda decisão de modelo usa esses dados

Fake.br (contexto)

  • 7.198 notícias, 2016–2018
  • 92,7% das fake de um só site (Diário do Brasil)
  • Não entra no modelo final: piora quando há corpus externo
  • Usado nos experimentos para entender limitações

Testes externos (avaliação única)

  • Teste 1: 39 itens (coleta 30/09/2026)
  • Teste 2: 77 itens (coleta 28/09–05/10/2026)
  • Coletados via RSS, sem escolha manual, conferidos só por conteúdo
  • Avaliados uma única vez em 05/10/2026 — não usados em nenhuma decisão

Por que TF-IDF de caracteres?

  • n-gramas de caracteres capturam grafia própria de boatos (MAIÚSCULAS, erros, pontuação)
  • Mais robusto que palavras em fontes novas — nunca perdeu para a base na validação cruzada de fontes (E6)
  • Empata com e5-small (embeddings 470 MB) com 200k features, sem GPU

Por que treino misto 30/50/100 palavras?

  • Treinar só com texto completo colapsa a classificação de trechos curtos: 99,8% das entradas curtas viram FAKE
  • Aumentar com 3 tamanhos diferentes expõe o modelo ao formato real do produto
  • Melhora em todos os tamanhos de entrada: N=30 (+0,8), N=50 (+0,7), N=100 (+1,6) vs treino fixo em N=50

# Pipeline exato do modelo escolhido
from sklearn.pipeline import Pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import LinearSVC

modelo = Pipeline([
    ("tfidf", TfidfVectorizer(
        analyzer     = "char_wb",    # n-gramas de caracteres dentro de palavras
        ngram_range  = (2, 5),        # bigramas a pentagramas de chars
        max_features = 200_000,      # vocabulário máximo
        sublinear_tf = True,          # log(tf) + 1
        dtype        = np.float32,    # memória
    )),
    ("svm", LinearSVC(
        C            = 1.0,            # regularização padrão
        class_weight = "balanced",   # compensa desbalanço fake/true no treino
        max_iter     = 20_000,        # convergência garantida
    )),
])

# Treino com data augmentation (misto 30/50/100 palavras)
def truncar(textos, N):
    return textos.str.split().str[:N].str.join(" ")

def aumentar(textos, labels):
    t = [truncar(textos, n) for n in (30, 50, 100)]
    return pd.concat(t), pd.concat([labels] * 3)

# Dados de treino: FakeRecogna 2020–21 + corpus externo (fr2021 + ext)
# Decisão: score >= 0 → "true";  score < 0 → "fake"
score = modelo.decision_function([trecho])[0]
classe = "true" if score >= 0 else "fake"

Experimentos

Jornada de decisões (30/09 – 05/10/2026)

Cada experimento usou apenas a validação externa — o teste final nunca foi consultado.

E0 · 30/09

Reprodução dos números de controle

Baseline só tamanho = 94,15% acc; TF-IDF N=50 = 89,88% F1. Confirmados com sklearn 1.6.1.

E1–E2 · 30/09–01/10

Coleta do corpus externo (2.849 itens)

RSS automático, sem escolha manual. Mesmo formato do produto: boato citado × início da matéria.

E4 · 01/10

Combinações de dados → corpus externo é o que muda

fr2021 + ext: F1 90,47. Modelos sem o externo ficam em 75–83. O Fake.br não acrescenta quando há o externo.

E5 · 05/10

12 variações de modelo → tudo empata (89–92%)

char_wb(2,5) vai a 91,43. word + char sem lowercase vai a 92,25, mas é o menos robusto na E6.

E6 · 05/10

Validação por fonte → char_wb nunca perde

Treinar sem E-farsas/Ag. Brasil e testar nelas: char_wb 80,20 × base 80,05. O modelo sem lowercase perde 3,5 pts.

E7 · 05/10

e5-small empata, mas sem medida de robustez

F1 91,77 vs char_wb 91,43. Requer torch + 470 MB; não passou pela E6. Descartado por custo e incerteza.

Por que 82% e não 94%?

Os boatos das páginas 5–10 do E-farsas são de períodos e temas variados — alguns com escrita mais jornalística. O Recall TRUE de 100% se mantém constante: o modelo nunca confunde notícia real com fake. A diferença está só nos boatos difíceis.

Limitações

O que o modelo não faz

Documentadas honestamente — essenciais para o relatório e para qualquer uso em produção.

1. Aprende estilo, não veracidade

O modelo distingue "jornalismo profissional" de "site opinativo / WhatsApp". Uma fake escrita em padrão jornalístico tende a passar como TRUE — os 5 erros do teste oficial são todos desse tipo.

2. Fake.br dominado por uma fonte

92,7% das fake do Fake.br vêm do Diário do Brasil. Nos experimentos anteriores, o modelo aprendia em parte a distinção "Diário do Brasil vs G1/Estadão".

3. Fontes novas custam ~10 pontos

Na validação cruzada por fonte (E6), o desempenho cai de ~91% para ~80% em fontes não vistas no treino. Parte do ganho é assinatura de site, não generalização por conteúdo.

4. Descompasso temporal no treino

Fake de 2022–jul/2026 × True de ago–out/2026. O modelo pode ter aprendido "assunto desta semana = true". O teste tem a mesma estrutura, então nem ele detecta esse atalho.

5. True do FakeRecogna são resumos automáticos

As 2.330 true de treino do FakeRecogna são resumos gerados por modelo, não texto original. Pode haver atalho de estilo do resumidor.

6. IC largo com n=116

F1 94,2% com IC [89–99]. Todos os modelos com corpus externo se sobrepõem. A medida confirma a direção mas não prova vencedor absoluto.
